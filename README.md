## Featured projects

### [Margaret School](https://github.com/Makarios44/margaretschool) — school management system *(in production)*
Administrative system for a private school in Pipa, Brazil: student records, enrollment and re-enrollment by secure link, tuition billing with fines, interest and receipts, official school documents, mobile-first daily attendance, school calendar with `.ics` feed, online pre-enrollment, photo albums with privacy controls and a step-by-step tutorial for non-technical staff.

`Django` `PostgreSQL` `Bootstrap 5` `Railway` · role-based access · login rate limiting · CSP · LGPD-aware

### [TravelPipa](https://github.com/Makarios44/TravelPipa) — multilingual tourism booking site · [travelpipa.com.br](https://travelpipa.com.br)
Booking website for a boutique travel agency in English, Portuguese and Spanish: tour catalog, booking requests with email notifications, custom mobile-friendly admin panel, technical SEO (hreflang, sitemap, JSON-LD) and live weather/tide data with caching and fallbacks. **119 automated tests.**

`Django 5.2` `PostgreSQL` `Docker` `Gunicorn` `Railway` · CSP/HSTS · anti-spam · pip-audit

### [Mini-Twitter](https://github.com/Makarios44/MINI-TWITTER) — social network web app
Built for a company's technical selection process.
